# 数据匹配助手 1.1.0

- 全新浅色 Windows 11 风格界面，支持浅色、深色、薄荷绿、深薄荷四种主题，并记住上次选择。
- 支持将 .xlsx 文件拖到窗口中选择，选中后突出显示文件名，并记住上次使用的路径。
- 处理完成后可打开结果所在文件夹。
- 新增「关于」窗口，包含作者、GitHub 链接和赞赏作者入口。
- 新增检查更新：启动后在后台检查，有新版本时在按钮上显示红点；点击后可一键下载、安装并重启。
- 两边都有学号时优先按学号匹配；没有学号时再按姓名。学号相同但姓名不同时仍写入，并在结束后列出差异。
- 名单里已有不同成绩时，写入前先确认是否覆盖，可全选、全部跳过或单条勾选。
- 成绩表空格会保留名单原成绩，并在问题窗列出；数字成绩超出 0～150 仍写入并列出。
- 支持打开 .xlsx、.xls 和 .csv。名单若是 .xls 或 .csv，结果另存为 .xlsx，不改动原文件。
- 处理顺利时弹出成功提示；有问题时列出清单，关闭后可在主界面再次打开。
