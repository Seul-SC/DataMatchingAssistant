# 数据匹配助手 1.3.0

- 安装包改用新的安装程序：安装时可以点「浏览」，把软件装到任意文件夹（比如 D 盘），也可以选择只给自己装或给这台电脑的所有人装；以后再安装或更新会自动沿用上次的位置。
- 检查更新改为读取 Gitee 上的版本信息。发现新版本时，「检查更新」按钮上会出现小红点；点「更新」后软件会下载新的安装包、校验无误后打开安装向导，按提示点几下就能装好，国内下载更快。
- 旧版（1.1.0 / 1.2.0）用户：在软件里更新到 1.3.0 后，会提示「新版改用新的安装方式，可自选安装目录」。点「下载并安装」即可换成新的安装方式，安装完成后旧版本会被自动删除，主题和最近打开的文件都会保留。
- 设置文件搬到 %AppData%\DataMatchingAssistant，换安装目录或卸载重装都不会丢失。
