# 数据匹配助手 1.2.0

- 外观主题调整为浅色、薄荷绿、同行、涟漪，深色仍可选用；已去掉深薄荷。鼠标悬停「外观」即可挑选主题，并记住上次选择。
- 同行、涟漪的配色与「同步待办」1.2.0 一致，只借用颜色。
- 成绩表里某次作业如果所有学生都是空的，问题窗不再把它列出来；只有同一作业有人有成绩、有人没有时，才会列出空分。空格仍然保持名单原样，不会被填上。
- 成功和问题弹窗里，有趣的那句话会显示在表情包右侧，并用更醒目的字体；写入结果放在表情包下方，问题条数则放在清单上方。
- 新用户请使用 MSI 安装程序，安装时可以选择当前用户或为所有用户安装。已经安装 1.1.0 的用户，在软件里一键更新到 1.2.0 后，仍会留在原来的文件夹；如果要换到其他磁盘，需要再运行一次新的 MSI。
- 检查更新改为向 Gitee 查询，国内下载会快一些。不会上传学生表格。
